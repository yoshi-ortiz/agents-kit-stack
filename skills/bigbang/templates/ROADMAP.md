# Roadmap

Start a session with `@ROADMAP.md`. The owner steers by chat; this page is where it lands.

- **Status** ("how are we doing?"): run `bigbang`, screenshot the project into `.bigbang/status/`, run
  `bigbang brief`, and answer with its Markdown and the screenshots attached. A ticket's state comes only from
  `bigbang` (tests and a committed receipt on base), never from this page or a tracker.
- **Priority** ("do X first"): rewrite `Order:`. **Spec** ("X should show Y"): edit that ticket's `entry:` or
  `visible:`, or add a ticket. Write the owner's words, not a guess; ask when they leave a choice open.
  Commit the edit with the trailer `Owner-Approved: <owner>` and the owner's words in the body.
- **Build** ("go"): follow `runbooks/loop.md` from the `next:` ticket.

One line per ticket: id · entry: where the user starts · visible: what they see when it works.
