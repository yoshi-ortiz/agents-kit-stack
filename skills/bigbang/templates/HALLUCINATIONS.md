# Hallucinations

Before acting on a remembered fact, check it against the owner below. The owner wins.

| Claim about | Owner |
| --- | --- |
| project facts (base, test, limits, ticket ids) | `guardrail.toml` |
| the owner's requirements | `docs/specs/requirements.md` |
| ticket state | `bigbang` output (`burndown:` lines), never a tracker status |
| token cost | `tanks/card.json` |
