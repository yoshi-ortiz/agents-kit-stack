## Question

Which real user Item, fixed acceptance criteria and available telemetry will
validate measurement, and what claims can that observation support?

## Proposal to evaluate

Start with one real Item to validate complete cost and feedback capture. Choose
a comparative cohort only if an improvement claim is needed; define assignment,
versions, sample size and incomplete/abandoned outcome treatment beforehand.

## Read when claimed

Read the portable adapter's accepted design, NEXT stage 6 and the relevant
engineering knowledge note. Confirm actual host telemetry instead of estimating
availability. Keep user verdicts distinct from test fixtures.

## Resolution evidence

The answer names the real Item, proof, usage source, stopping budget and
measurement-only or comparative scope. Criteria and evaluation rules are explicit;
no future user acceptance or correction is presumed.
